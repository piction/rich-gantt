Move several tasks together

Extends focus mode: today one focused bar can be dragged / nudged with ←→. Goal: select several bars and move them as one block. Only moving — no group edit/delete. Four ways to build the selection; all share the same move semantics.

Worth knowing: successors that are after a moved task already follow it. Multi-select is for the tasks that don't follow on their own: pinned tasks, tasks in other branches, or a task together with its predecessors.

Shared move semantics (all options)

  • One delta for the block. Every member shifts by the same number of days (working days when weekends are excluded).
  • Internal links are kept — a member after another member is not touched in the source.
  • Incoming links are cut — members with a predecessor outside the block are pinned (moveTask) to old start + delta. Previewed red/scissors, same as today.
  • Outgoing successors cascade via the scheduler, as today.
  • One commit → one commitDocument, so the code editor sees a single change.

Recommendation: 1 + 2

Build the selection set + group move once (option 1, small change), then add the marquee on top (option 2) — together they cover "a few picks" and "this block", both are known conventions, and neither steals an existing gesture. Option 3 is a cheap later add-on reusing the same engine; option 4 is a separate tool, only worth it if "push the rest of the plan" is a frequent need.
