Recommendation

B (leading split button) + C (in-chart "+") — E later as an extra

  • B is the always-visible entry point: first in the toolbar, next to Zoom, set apart by its fill and a divider. The ▾ menu gives "New section" a home without adding a second button.
  • C is the in-context shortcut. "+" next to a section name pre-fills that section, and the "+ Section" row at the bottom matches the menu entry. Both use the same popover.
  • E (double-click empty space) is the fastest path for power users and fills in both section and date. It is invisible, so it should never be the only way in.
  • Keys: N new task, ⇧N new section, A add-after on the focused bar.

Constraint: a section can't exist empty

The parser only creates a section when a task line is attached to it, so an empty section X disappears after serialize → re-parse. That's why "New section" always creates its first task too: same popover, with a section-name field on top. This turns out to be good UX anyway, because there are no empty, invisible sections to manage.
